# Credits

Expo Starter builds on the work of the open-source community.

## Core stack

- [Expo](https://expo.dev) and [Expo Router](https://docs.expo.dev/router/introduction/) — app
  platform and file-based navigation
- [React Native](https://reactnative.dev) and [React](https://react.dev) — UI runtime
- [TypeScript](https://www.typescriptlang.org) — type system
- [NativeWind](https://www.nativewind.dev) and [Tailwind CSS](https://tailwindcss.com) — styling
- [React Native Reusables](https://reactnativereusables.com) and
  [rn-primitives](https://github.com/founded-labs/react-native-reusables) — components; this
  project started from the React Native Reusables template
- [React Hook Form](https://react-hook-form.com) and [Zod](https://zod.dev) — forms and validation
- [i18n-js](https://github.com/fnando/i18n) — localization
- [Bottom Sheet](https://github.com/gorhom/react-native-bottom-sheet) — bottom sheets
- [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/),
  [Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler/), and
  [Screens](https://github.com/software-mansion/react-native-screens) — animation, gestures, and
  native screens
- [React Native Keyboard Controller](https://github.com/kirillzyusko/react-native-keyboard-controller)
  — keyboard handling
- [Lucide](https://lucide.dev) — icon set
- [Jest](https://jestjs.io) and
  [React Native Testing Library](https://callstack.github.io/react-native-testing-library/) — tests

Plus the Expo modules for haptics, local authentication, store review, tracking transparency, image
picker, localization, linking, splash screen, and status bar.

See each project's license for terms.
