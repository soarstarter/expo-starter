## Refresh guidance

- Treat this list as a baseline snapshot.
- If a component is missing here, check the latest CLI/official docs before creating a custom component.
- In implementation tasks, always prefer:
  1. existing local `components/ui/*`,
  2. installable reusables component via CLI,
  3. custom component only when needed.
